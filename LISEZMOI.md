# LexNav Android

Navigateur LexOS pour Samsung — noir, écriture blanche, accents orange, tout arrondi.

- Page d'accueil avec ton fond LexOS : intro zoomée, respiration, néon qui clache
- Onglets (bouton du compteur en bas) : fermer, fermer les autres, tout fermer, rouvrir
- ✳ Claude dans un panneau qui monte du bas (⤢ pour l'ouvrir en onglet)
- Bloqueur de pubs, favoris, moteur de recherche au choix, téléchargements, partage
- Peut devenir ton navigateur par défaut

L'APK se construit tout seul avec GitHub Actions à chaque `git push` :
onglet **Releases** du dépôt → `LexNav.apk`.
